Subcontractor Management & Certificates

Manage subcontracts the same way you manage client contracts: BOQ, retention, advance, and payment certificates, but on the vendor side. Certificates become vendor bills with retention payable and advance recovery. Requires Progress Billing (IPC).

Key features

✔ Subcontracts under the main contract
Linked to the client contract, project and analytic account.
✔ Subcontract BOQ and terms
Retention, advance, defects period and purchase taxes.
✔ Subcontractor certificates
Same certificate engine as client billing, with approval.
✔ Vendor bills automatically
Work done, retention payable, advance recovery and back-charges on vendor-side accounts.
✔ Cost on the main contract
Subcontract bills land on the main contract's analytic account for cost control.
✔ Subcontracted value
The main contract shows the value of subcontracts placed.

How it works

1Set the bills journal and vendor-side accounts in Settings > Contracting.
2From the main contract click New subcontract, choose the subcontractor and add the BOQ.
3Confirm, then create subcontractor certificates as work progresses.
4Approve and create the vendor bill in one click.

Configurable in Settings

Bills journal, product, cost accountFor work done
