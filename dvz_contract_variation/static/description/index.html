Variation Orders for Contractors

Handle change orders properly. Record site instructions, add new BOQ items or change quantities and rates, get approval, and update the contract value without touching the original BOQ. Requires the free Contracts & BOQ app.

Key features

✔ New items and changes
Add new BOQ items, or increase / reduce quantities of existing items.
✔ Reason and instruction reference
Client instruction, design change, site condition, omission.
✔ Approval workflow
Draft, submitted, approved, applied, rejected. Approval can be switched off.
✔ Apply to BOQ
Approved variations add auditable variation lines to the BOQ and update the contract value.
✔ Time extension
Extend the planned completion date in days.
✔ Omissions
Negative variations, which you can allow or block.
✔ Variation order PDF
Printable document for client sign-off.

How it works

1Choose approval and auto-apply in Settings > Contracting.
2From a contract in progress click New variation and add the changes.
3Submit and approve. The BOQ and contract value update automatically.
4The next payment certificate picks up the new items (with Progress Billing).

Configurable in Settings

Variations need approvalOn / off
Apply variations on approvalOn / off
Allow omissionsOn / off
